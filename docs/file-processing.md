# Обработка файлов HackAlem

## Лендинг HackAlem: `index.html` → `app.landing`

**Файлы не загружаются в постоянное хранилище.** POST `/api/chat` принимает текст и список `{name, data}` с base64. Проверки размера, структуры Office/PDF и параметров изображений выполняются на сервере.

- DOCX: `python-docx` извлекает абзацы и ячейки таблиц.
- XLS/XLSX: `python-calamine` читает листы и значения ячеек; макросы не выполняются. Коды с ведущими нулями лучше хранить как текст: числовая ячейка может их потерять ещё в Excel.
- TXT/CSV: UTF-8. Для офисного текста есть проверка известных шаблонов платёжных данных до передачи модели.
- PDF: OpenAI получает файл, включая визуальную информацию страниц. Текстовый PDF и PDF со сканом проверены отдельно. Защищённые паролем документы отклоняются.
- JPEG/PNG: после проверки изображения OpenAI получает `input_image`; читаемые коды сопоставляются с каталогом, внешний вид не считается доказательством точной модели.
- Старый DOC: передаётся как `input_file`; живой контрольный DOC не проверен, для Word рекомендуется DOCX.

Responses API с `store=False` возвращает структурированное намерение и позиции. Сервер получает реальные карточки через API ekt.kz; ответ модели не служит источником цены и наличия. Каждая распознанная позиция попадает в проверку: запрос, количество, найденный товар, доступность и причина уточнения. Единственная нечёткая поисковая находка не считается точным совпадением. Количество без значения не подставляется. Повторы суммируются с учётом текущей корзины. Пользователь сверяет полноту с оригиналом и выбирает готовые строки; только затем сервер готовит предложение для отдельного согласия. Вложения **никогда не считаются подтверждением** изменения корзины.

Лимиты и инструкция запуска: [README](../README.md#как-обрабатываются-файлы). Содержимое файлов хранится только на время запроса. История сессии содержит текст диалога и имена файлов, но не байты документов. Данные передаются провайдеру OpenAI; `store=False` отключает сохранение объекта ответа, а не все возможные сроки хранения провайдера. Пользователь видит уведомление перед отправкой; платёжные данные прикладывать нельзя.

Проверено 23.09.2026: DOCX, XLS, XLSX, текстовый PDF и JPEG с `027228`, каждый в новой сессии, нашли товар ID `515291`, корзина осталась пустой. Эти примеры проверяют извлечение кода; качество сложных таблиц и распознавания произвольных фотографий не гарантируется. Автономный режим `file://` использует прежние браузерные парсеры и OCR; он явно обозначен как демо.

Документация провайдера: [файлы](https://developers.openai.com/api/docs/guides/file-inputs), [структурированные ответы](https://developers.openai.com/api/docs/guides/structured-outputs).

В контракте `ChatReply.review` содержит типизированные строки, а `products` — исходные товарные факты. Pydantic остаётся владельцем схемы; JSON OpenAPI перегенерирован. Статусы: готово, не найдено, неоднозначно, нужно количество, неверное количество/кратность, нет/не хватает остатка, источник недоступен. Модель не назначает эти статусы — их рассчитывает сервер. Список охватывает извлечённые моделью позиции, не гарантирует отсутствия пропусков в исходном документе.
