# План работы — кейс ekt.kz

Статус: **план, не отчёт о выполнении**. Ориентир — 5 часов хакатона. Главная задача из [Word ТЗ](<assets/HackAlem AI_ ИИ-ассистент для чата на сайте ekt.kz.docx>): помочь покупателю принять решение в одном чате на основе каталога и, после явного согласия, перейти к актуальной корзине. [PRD](PRD.md) задаёт поведение; [Use Cases](use-cases.md) — прогоны. Используем существующие FastAPI/Pydantic и Next.js/React только по потребности сценария.

1. **Сейчас: довести UC-01 до видимого результата для клиента.** На основе [проверенного контракта API](../../contracts/ekt-catalog-api.md) найти способ сопоставления артикула с числовым `id`, настроить Basic Auth через локальные секреты, выбрать контрольный и отсутствующий артикулы, уточнить источник сертификатов. Соединить минимальный чат → наш API → фактическое чтение детальной карточки → ответ с характеристиками, наличием, источником и временем получения. Неизвестные поля и сбои источника показывать честно. Проверить значения относительно источника в API-тесте и результат в браузере; записать, был ли прогон живым или демонстрационным. **Это первый критерий продвижения; без него следующие UC не считаются приоритетом реализации.**
2. **После проверенного UC-01: UC-02 (п. 2 Word ТЗ).** Добавить релевантный доступный аналог для нулевого остатка из того же каталога, с объяснением совпадений и отличий; сверить его артикул, характеристики и остаток с источником.
3. **Затем: UC-03 (п. 3).** Получить утверждённый источник условий покупки и проверить ответы об оплате, доставке и минимальной партии. Пока источника нет, явно обозначать ограничение.
4. **Затем: UC-04 (п. 4).** Согласовать контракт корзины и идентичность покупателя; реализовать отдельное явное согласие, повторную проверку остатка и единственное ожидаемое изменение корзины. Проверить отмену, двусмысленность и превышение остатка.
5. **Затем: UC-05 (п. 5).** После успешного UC-04 дать прямую ссылку и проверить, что она открывает актуальную корзину ekt.kz с добавленной позицией.
6. **Полный прототип и сдача.** Подключить заявленные фото и файлы Excel, Word, PDF, JPEG к той же цепочке в рамках разрешённой обработки данных; проверить мобильный экран, приватность и отсутствие платёжных данных. Провести живые прогоны UC-01…05, записать вход, источник и результат каждого критерия, обновить README и CHANGELOG.

Вопросы о правилах данных, условиях покупки, корзине и встраивании можно отправить партнёру параллельно с шагом 1. Недоступную интеграцию не подменять вымышленными данными: синтетический каталог и локальная корзина допустимы только как явно обозначенная демонстрация.
