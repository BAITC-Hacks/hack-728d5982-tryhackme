Подключение к каталогу
Каталог работает с приложенной выборкой. Для актуального наличия и новых товаров можно подключить API ekt.kz.

Пароль используется только для текущей вкладки и не сохраняется.

Браузер должен иметь доступ к ekt.kz, а API — разрешать запросы с домена страницы (CORS). Если CORS закрыт, подключите серверный шлюз на своём домене.

Этот файл не содержит секретов, серверной логики ИИ и интеграции с реальной корзиной. Для работы на сайте потребуется серверный слой и подтверждённый API корзины.
